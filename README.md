# FWS Prismia — студия и инструменты материалов

Prismia — самостоятельная WebGL-студия и библиотека материалов. Общие инструменты
строятся из графа 2D-текстур и настраиваемой модели освещения PBR, toon или unlit;
заготовки — обычные редактируемые данные, а не набор отдельных брендированных
шейдеров. Prismia предоставляет Morphia общий движок материалов и каталог
пресетов. Это отдельная студия, не панель Morphia. Пакет приватный (`private`).

Разделы «Окружение», «Отображение» и «Графика» и каталог карт предоставляет
общий `viewport3d`. Студия использует прежнюю сетку предпросмотра Prismia;
общий контроллер управляет видимостью, а Prismia освобождает свой `GridHelper`.
Дополнительные карты обнаруживаются при сборке в `src/plugins/worlds/<id>/`;
формат manifest и владение ресурсами описаны в README общего viewport3d.

## Prismia Studio

Откройте `standalone/index.html` в браузере с WebGL 2. Это одна автономная
страница на `uix-preparatorio` и `framework-preparatorio`: код, стили и
лицензии включены в HTML; сервер и сеть для работы не нужны. Меню **Файл →
Лицензии компонентов** показывает текст лицензий. На узком экране панели
переключаются вкладками; на широком — доступны одновременно и переставляются.
Доступность WebGL, файловой загрузки и скачиваний зависит от браузера и его
ограничений; во встроенном sandbox-предпросмотре некоторые браузеры запрещают
скачивание и сохранение в локальное хранилище. Для экспорта откройте скачанный
HTML в обычной вкладке.

### С чего начать

При первом открытии показан «Мой первый материал»: два источника слева — цвет и
серое значение шероховатости — соединены с двумя выходами справа. Щёлкните узел,
и в **Свойствах** появится объяснение и его параметры. Цвет меняется в узле
«Однородный цвет», а **Материал** задаёт поведение света на поверхности.

1. **Библиотека** содержит 29 типов узлов, 15 редактируемых готовых материалов и
   6 стилей поверхности. Щелчок по готовому материалу после подтверждения меняет
   граф и стиль; отмена возвращает предыдущий. Стиль меняет только настройки
   поверхности, не заменяя узлы. Узел можно добавить щелчком, перетаскиванием
   из библиотеки или кнопкой «＋ Узел» в графе. Есть поиск и избранное.
2. **Граф узлов** передаёт изображения слева направо. Перетащите кружок выхода
   справа на кружок входа другого узла либо нажмите сначала выход, потом вход.
   От одного выхода можно вести несколько связей. Кнопка «2D» показывает
   результат узла; «×» в заголовке удаляет узел с его связями, а «×» у входа
   разъединяет только этот вход. Эти действия можно отменить. Дополнительная
   памятка находится под «Как это работает?». Кнопки «−»/«＋» и колесо меняют
   масштаб, пустое место перетаскивает граф, «Уместить граф»/F показывает всё;
   Space/Tab открывает поиск, Delete удаляет выделенное, Ctrl+Z и Ctrl+Shift+Z
   отменяют и повторяют. На сенсорном экране также работают два нажатия на порты.
   Циклы и повторные выходы одного канала не допускаются.
3. В **Материале** выберите готовый стиль или модель PBR, toon либо unlit и
   подстройте цвет, ступени света, блик, краевой свет, контур, прозрачность и
   свечение. PBR-ползунки шероховатости и металличности задают постоянное
   значение без карты или множитель при подключённой карте. Нормали имеют
   приоритет над высотой. Цветные тени и блик — настройки toon; в unlit
   освещение сцены на саму поверхность не влияет. **Свет** и **Сцена** меняют
   окружение, камеру, форму и локально загруженную GLB-модель.
4. **Код GLSL** показывает код выбранного отдельного прохода. Узел «Узел GLSL»
   можно редактировать и проверить компилятором WebGL: доступны `tex_source`,
   `tex_mask`, `uTexel`, `uSeed`, `uTime`. При ошибке сохраняется последняя
   рабочая версия. Анимация `uTime` пересчитывается с ограничением частоты.
   «↓ GLSL» скачивает фрагмент прохода, а не цельный шейдер всего графа.
5. **2D вид** показывает выбранный узел, RGBA-каналы и повторение. Во вкладке
   **Выходы** подключённые карты можно экспортировать в ZIP с 8-битными PNG
   размером 256–2048. Base Color и Emissive интерпретируются как sRGB, остальные
   карты — как линейные данные; AO из высоты — приближение, не bake геометрии.
   **PNG содержит карты графа, а не живое освещение, контур или настройки
   поверхности.** Снимок 3D — отдельное изображение, не переносимый материал.
6. **Файл → Сохранить проект JSON** сохраняет граф, связи, опубликованные
   параметры, `surface` и встроенные изображения. При возможности граф также
   восстанавливается из `localStorage`, но это не замена файлу. Старые JSON без
   `surface` получают значения по умолчанию. Изображения PNG/JPEG/WebP до 8 МиБ
   можно встроить узлом «Изображение»; суммарно — до 12 млн символов base64,
   максимальный размер открываемого JSON — 16 МБ. GLB до 80 МиБ должен содержать
   встроенные ресурсы, без Draco и внешних URL; в JSON модель не записывается.

**Пример маски:** выберите стиль «С краевой подсветкой», добавьте узлы «Серое
значение» и «Выход материала». Выделите выход и в его свойствах выберите
«Маска краёв · rimMask», затем соедините с ним серое значение. Чёрный (0)
убирает эффект, белый (1) оставляет его полностью; вместо константы можно
соединить любую маску из графа. Аналогично «Маска блика · specularMask»
управляет бликом, если выбрана модель toon и яркость блика больше нуля.
Маски читают **красный** канал. Карты roughness и opacity читают зелёный,
metallic — синий, AO и height — красный; серые узлы записывают одинаковые RGB.

Контур — дополнительная оболочка, смещённая по нормалям в пространстве объекта:
его вид зависит от масштаба и геометрии. Он не строится для `InstancedMesh`,
не повторяет альфа-вырезы и отдельные группы материалов. Для геометрии нужны
нормали. Это не screen-space outline; его следует проверять на конкретной модели.
Бюджет render targets ограничен приблизительно 256 МиБ, поэтому для сложного
графа на 2048² может понадобиться меньший размер.

Это **собственный ограниченный редактор**, вдохновлённый рабочим процессом
Substance 3D Designer, а не эквивалент Adobe. Форматы **SBS/SBSAR не читаются
и не публикуются**, нет пакетного запекания геометрии, UDIM, HDR-выходов,
физической симуляции или полного каталога Adobe. Не всякий процедурный генератор
бесшовный. Редактор является новой реализацией: предыдущие исходные разделы
«Граф узлов» и «Код GLSL», упомянутые пользователем, в доступной копии
проекта отсутствовали и не могут считаться сохранёнными без оригинальной сборки.

### Разработка и проверки

Нужны Node.js >= 20.19, npm и Git. При первой установке нужен доступ к npm и
GitHub; каркас из этой поставки сначала нужно опубликовать и заново разрешить предварительный lockfile. В ряде окружений
npm переписывает GitHub-адреса на SSH, тогда настройте HTTPS вместо SSH либо
предоставьте доступ к GitHub. Готовый HTML от установки не зависит.

```bash
npm ci
npm run dev                 # Vite, адрес из терминала
npm test                    # DAG, поверхности, API и каталог Prismia
npm run build               # обновляет standalone/index.html
npx playwright install chromium
npm run test:viewport3d    # расширения и жизненный цикл области
npm run test:graphics      # общие настройки и реальный renderer
npm run test:studio         # GLSL, real WebGL frames, desktop/mobile, экспорт
```

Браузерная проверка по умолчанию открывает автономный файл. `CHROMIUM_PATH`,
`PRISMIA_URL` и `OUTPUT_DIR` можно переопределить. Тест использует программный
SwiftShader; производительность и визуальный результат конкретного GPU нужно
проверять отдельно.

## Публичные API студии, scopes и графа

```js
// Для браузерной интеграции с собственным сборщиком, например Vite:
import 'uix-preparatorio/styles.css';
import 'fws-prismia/styles.css';  // содержит также стили страницы-хоста
import { createPrismiaStudio } from 'fws-prismia/studio';

const prismia = await createPrismiaStudio({ mount: '#app', restore: true });
const graphChannel = prismia.exchange.channel('graph');
const stop = graphChannel.subscribe(state => console.log(state.project.name));
graphChannel.dispatch('setSeed', 42);
// Когда область больше не нужна:
stop();
prismia.destroy();
```

`fws-prismia/scopes` экспортирует паспорта десяти областей, composition/bind,
state и `createScopeExchange`; взаимодействие идёт через `graph`, `view` и
`render`, команды каналов ограничены явными списками. Реализация каждой области
получает контекст и возвращает функцию освобождения. Собственную composition
можно передать при создании. Публичный `fws-prismia/shaders` предоставляет тот же API, что и корневой
`fws-prismia`; `fws-prismia/graph` предоставляет узлы, проверку и вычислитель.
Все указанные входы включены в npm-архив; пакет пока приватный и не опубликован.

### Редактируемые материалы и применение в хосте

```js
import { listMaterialPresets, createMaterialPreset, listSurfacePresets,
         createSurfacePreset, attachSurfaceOutlines } from 'fws-prismia/materials';
import { createGraphStore, GraphEvaluator, createOutputTextures,
         createGraphMaterial } from 'fws-prismia/graph';

console.log(listMaterialPresets()); // id, название, описание; 15 заготовок
console.log(listSurfacePresets());  // 6 настраиваемых стилей
const project = createMaterialPreset('toon-ink'); // новая независимая копия
const graph = createGraphStore(project);
graph.setParam('color-map', 'high', '#d8a6f0');
graph.setSurface('rimStrength', 0.8);
graph.setSurface('specularSize', 0.55);
// Также можно получить отдельный набор параметров и изменить его:
const surface = createSurfacePreset('toon-soft');
surface.toonSteps = 4;
// graph.setSurfaceValues(surface);  // применяет стиль целиком; граф не меняется

// renderer и mesh принадлежат вашему приложению, используют тот же Three.js.
const evaluator = new GraphEvaluator(renderer);
await evaluator.prepareBitmaps(graph.value.project);
evaluator.evaluate(graph.value.project, { time: 0 });
const textures = createOutputTextures(evaluator); // копии, принадлежат хосту
const material = createGraphMaterial(textures, graph.value.project.surface);
const previous = mesh.material;
mesh.material = material;
const outline = attachSurfaceOutlines(mesh, graph.value.project.surface);
// ...renderer.render(scene, camera)...

// Перед заменой геометрии/материала: убрать оболочку, вернуть исходник и
// освободить собственные ресурсы. Переданные текстуры Prismia не освобождает.
outline.dispose();
mesh.material = previous;
material.dispose();
Object.values(textures).forEach(texture => texture.dispose());
evaluator.dispose();
graph.dispose();
```

Для уже существующих карт без графа: `createSurfaceMaterial({baseColor, normal,
roughness, metallic, height, ambientOcclusion, emissive, opacity, rimMask,
specularMask}, settings)`. Каждый ключ карты необязателен. Значения `settings`
проверяет `validateSurface`; схема и значения по умолчанию доступны как
`SURFACE_SCHEMA` и `SURFACE_DEFAULTS`. `roughness`/`metalness` умножают карту,
а `roughnessBase`/`metalnessBase` задают значения, когда соответствующей карты
нет. `rimMask` работает с PBR/toon/unlit, `specularMask` — с toon. Контур
создаётся отдельно через `attachSurfaceOutlines` и требует `dispose()`; он
делит геометрию и скелет с исходным мешем и не владеет ими. Программные эффекты
используют `onBeforeCompile` и рассчитаны на WebGL и проверенную версию Three.js,
а не на универсальный перенос в любой renderer.

Изменение данных проекта само по себе не меняет созданный материал: хост должен
пересчитать выходы графа при необходимости и пересоздать материал и контур,
удалив прежние собственные ресурсы. Вычислитель владеет кэшированными render
targets, сохраняет целевой framebuffer хоста и пересчитывает изменённые узлы и
потомков. Перед экспортом изображений вызовите `prepareBitmaps`. Управление
состоянием и undo доступны через `createGraphStore` и `graph`-канал, а списки
ключей каналов и их русские подписи — через `OUTPUT_USAGES` и `OUTPUT_LABELS`.

## Установка пакета и API материалов

Диапазон peer-зависимости — Three.js >= 0.186.1 и < 0.188.0; в этой
сборке проверена версия 0.186.1. `three` — **peer**: хост должен использовать
один экземпляр Three.js. Надёжный локальный вариант —
упаковать библиотеку и установить полученный архив в проект:

```bash
cd /путь/к/fws-prismia
npm pack                         # fws-prismia-1.0.0.tgz
cd /путь/к/моему-проекту
npm install three@0.186.1 /путь/к/fws-prismia/fws-prismia-1.0.0.tgz
npm ls three                     # один экземпляр, deduped
```

Упакованный файл исключает вложенные dev-зависимости. Если подключаете папку
напрямую, избегайте символической ссылки с собственным `node_modules`: она
может создать второй экземпляр Three.js. Для Vite/монорепозитория настройте
`resolve.dedupe: ['three']` и peer resolution в сборщике.

```js
import { ShaderEngine, createPrismiaRegistry } from 'fws-prismia';

const shaders = new ShaderEngine({
  registry: createPrismiaRegistry(),
  targets: ['world'],
  defaults: { world: 'original' },
  renderer, // WebGLRenderer хоста; нужен для процедурного IBL
});

shaders.setSelection('world', 'wet-asphalt');
shaders.applyToObject(mySurface, {
  defaultTarget: 'world',
  skip: (mesh, mat) => mat.isShaderMaterial || mat.isRawShaderMaterial,
});

// В игровом цикле: абсолютное прошедшее время в секундах.
shaders.update(clock.getElapsedTime());
// ...renderer.render(scene, camera)

// Возврат оригиналов и освобождение материалов, созданных Prismia:
shaders.reset();
shaders.dispose();
```

Реестр можно расширять `registry.register({ id, label, group, build })`. `build`
получает исходный материал и контекст; движок не строит новый пресет поверх
предыдущего. Текстуры источника остаются собственностью хоста. Состояние выбора,
сбор записей по целям, события и `materialSignature` доступны из
`fws-prismia`. Каталог отдельно доступен
из `fws-prismia/presets`, свет и контроллер теней — из `fws-prismia/lighting`.
Подпуть `fws-prismia/material-builders` экспортирует общие построители
материалов и градиентов для адаптеров; Rephlexia использует его, сохраняя
свои авторские toon-градиенты. Этот экспорт необходимо опубликовать вместе
с остальным снимком Prismia.

В каталоге Prismia для `world` и `preview` доступны, например:

* **wet-asphalt** — PBR с процедурной маской луж в мировых координатах,
  изменением шероховатости и анимированной нормальной рябью;
* **sunrise-ground** — процедурная зернистость поверхности с сохранением
  исходного цвета и текстур;
* **clearcoat-paint** — физический лак с верхним покрытием.

Отражения этих материалов — отражения **окружения IBL**, не screen-space и не
плоское зеркальное отражение реальных объектов. Это WebGL-реализации, а не
перенесённые напрямую WebGPU/TSL-шейдеры Project Endurance. Готовые карты с
собственными процедурными `ShaderMaterial` не заменяются автоматически в Morphia.
Глобальный выбор шейдера мира действует на все подходящие обычные меши карты,
а не только на дорогу; для точечного применения в своём хосте передайте
конкретный объект или используйте `skip`/целевые группы.

## Свет и тени

`DirectionalShadowVolume` ограничивает ортографическую область теней,
перемещает её вслед за позицией и привязывает к целым теневым текселям.
Он предназначен для `DirectionalLight` и его target — непосредственных
потомков одной не масштабированной сцены. `extent` — **половина ширины карты в
метрах**, а не бесконечная дальность. В пределах ресурса одна карта теней всегда
представляет компромисс между дальностью и детализацией; это не каскадные тени.

```js
import { DirectionalShadowVolume } from 'fws-prismia/lighting';
const volume = new DirectionalShadowVolume({ scene, light: sun, extent: 22 });
// После обновления камеры и направления света, перед render:
volume.update(player.position, { viewDirection: cameraDirection, lead: 4 });
renderer.shadowMap.needsUpdate = true; // если autoUpdate выключен
```

`createLookMixer({scene, renderer, hemiLight, ambientLight, keyLight, fillLight,
rimLight})` умеет `set('sunrise', {duration: 0.7})` и `update(dt)`; встроенные
профили доступны как `LOOK_PROFILES`. Кастомный профиль должен задавать полный
набор полей из одного встроенного профиля.

## Источники и пределы

Сравнение с Evolvia использовано для балансировки света, не для обещания
идентичной картинки. [Ocean Drive](https://github.com/StarKnightt/ocean-drive)
дал ориентиры по движущемуся ограниченному объёму и работе с качеством;
соответствующая лицензия MIT и лицензия Three.js лежат в
`THIRD_PARTY_NOTICES.txt`. [Project Endurance](https://endurance-racing.vercel.app/)
и [описание приёмов](https://andersonmancini.dev/blog/endurance-racing) изучены
как референс, код или ресурсы оттуда не копировались. Видеокарта, настройки
экспозиции, текстуры, вид карты и авторские материалы существенно влияют на
результат.


## Общий viewport3d

Базовая область и runtime находятся в `framework-preparatorio/src/scopes/viewport3d`.
Для разработки каркас устанавливается из Git-зависимости
`framework-preparatorio`; локальная копия в проекте не нужна.
Область в каркасе по умолчанию скрыта; конфигурация приложения явно включает
`builtInScopes.viewport3d.enabled`. Сцена, камера, основной renderer и плагины
используют Three.js хоста; граф материала, свет и управление остаются в
`src/plugins/viewport3d/`. Канонический scope — `viewport3d`, прежний lookup
`registry.get('viewport')` сохранён. Документация runtime:
`framework-preparatorio/src/scopes/viewport3d/README.md` установленного пакета.

В шапке доступны общий режим «Просмотр» с инструментом «Обзор» и подробная
панель «Графика». Списки с описаниями и ползунки берутся из Preparatorio,
название не повторяется под вкладкой. Экспозиция и включение теней синхронизированы с панелью
«Свет»; настройки графики сохраняются отдельно от JSON-проекта в
`localStorage` под ключом `fws-prismia.viewport-graphics.v1`. При запрете
хранилища вид работает без сохранения. Сброс в панели сбрасывает графические
параметры, не граф материала.

При использовании `fws-prismia/studio` приложение должно установить Three.js
и **обновлённую редакцию** `framework-preparatorio` из этой поставки: прежний
публичный commit 1.2.0 ещё не содержит новых графических экспортов. Версии в
`package.json` сами по себе не гарантируют наличие нужного commit. Для сборки
через Git сначала опубликуйте изменения каркаса и обновите Git-lock Prismia:

```bash
mv package-lock.json package-lock.provisional.json  # сохранить старый lockfile
npm install --package-lock-only --ignore-scripts
# проверить настоящий commit каркаса в новом lockfile
npm ci
npm run build
npm run test:viewport3d
npm run test:graphics
```

Проверьте, что `node_modules/framework-preparatorio` в `package-lock.json`
закреплён на опубликованном commit с новыми экспортами. Браузерные проверки
требуют Chromium Playwright; `test:viewport3d` также проверяет встроенную область
каркаса. Для API материалов Prismia каркас необязателен.
